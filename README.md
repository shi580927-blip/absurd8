# Кот, который слишком хорошо живёт

Абсурдный HTML5-кликер для мобильных устройств, компьютеров и будущей публикации на Яндекс Играх.

## Первая версия

- клики по коту и кнопке кормления;
- пять улучшений;
- пассивный доход;
- шесть уровней наглости;
- случайные реплики;
- офлайн-доход до четырёх часов;
- автоматическое сохранение в `localStorage`;
- адаптивная вёрстка без внешних библиотек и ассетов.

## Запуск

Откройте `index.html` в браузере. Для публикации можно включить GitHub Pages: **Settings → Pages → Deploy from a branch → main / root**.

## Следующее обновление: тамагоччи и игрушки

- интерактивные игрушки: туннель, игровой комплекс-замок, беговое колесо и другие кошачьи развлечения;
- короткие анимации и мини-игры, связанные с каждой игрушкой;
- смешные режимы поведения Шефа, включая «режим изгнания бесов»;
- массаж морды: игрок угадывает приятную зону, а за ошибку может получить лапой;
- развитие коробки и новые фоны после проверки первой версии игроками.

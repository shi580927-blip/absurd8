# Чек-лист VK Mini Apps + Одноклассники — Кот Шеф

Использовать перед каждой загрузкой ZIP VK/ОК-версии.

Версия готова только после прохождения применимых пунктов.

## 1. Безопасность веток

- [ ] Работа выполняется в `platform/vk-ok`.
- [ ] `main` не изменён работами по VK/ОК.
- [ ] В VK/ОК-ветке нет случайного merge обратно в Яндекс.
- [ ] Изменения игровой логики отсутствуют, если они не были отдельной задачей.

## 2. Состав ZIP

- [ ] `index.html` находится в корне ZIP.
- [ ] В архиве есть `scene.html`, `game.js`, `platform-vk-ok.js` и необходимые CSS.
- [ ] Все необходимые игровые ассеты включены.
- [ ] В архив не попали `.git`, документы разработки, `submission-assets`, `scripts` и временные файлы.
- [ ] В именах файлов и папок нет проблемных пробелов/кириллицы.
- [ ] Архив открывается без ошибок.
- [ ] Загружена именно последняя сборка ветки `platform/vk-ok`.

## 3. Проверка отсутствия Яндекс-зависимостей

- [ ] Нет `/sdk.js`.
- [ ] Нет `YaGames.init()`.
- [ ] Нет `ysdk`.
- [ ] Нет `yandexPlayer`.
- [ ] Нет `LoadingAPI`.
- [ ] Нет `GameplayAPI`.
- [ ] Нет `showRewardedVideo`.
- [ ] Нет обязательной зависимости от `ysdk.environment.i18n.lang`.

## 4. VK Bridge

- [ ] VK Bridge загружается.
- [ ] `VKWebAppInit` завершается без критической ошибки.
- [ ] В test mode статус `bridge=OK`.
- [ ] Игра не зависает, если Bridge временно недоступен.
- [ ] Вне платформы local fallback не ломает запуск.

## 5. Язык

- [ ] Рабочая VK/ОК-версия запускается на русском.
- [ ] Нет случайного переключения на английский через старую Яндекс-логику.
- [ ] Старые EN-ассеты/строки не удалены из проекта без отдельной задачи.

## 6. Сохранения

- [ ] Новый игрок стартует корректно.
- [ ] Локальное сохранение работает.
- [ ] `VKWebAppStorageSet` сохраняет состояние.
- [ ] `VKWebAppStorageGet` возвращает состояние.
- [ ] Большое состояние корректно разбивается на части.
- [ ] После перезагрузки прогресс сохраняется.
- [ ] Более новое облачное состояние корректно подхватывается.
- [ ] Ошибка cloud save не уничтожает локальный прогресс.
- [ ] Test mode не записывает тестовый прогресс в облако.
- [ ] Повторный вход не дублирует награды/доход.

## 7. Rewarded — VK

- [ ] Используется `VKWebAppShowNativeAds`.
- [ ] Используется формат `reward`.
- [ ] До фактического старта рекламы cooldown не включается.
- [ ] При успешном просмотре награда выдаётся один раз.
- [ ] При закрытии/ошибке награда не выдаётся.
- [ ] После рекламы звук и игра корректно возобновляются.
- [ ] Нельзя запустить вторую рекламу поверх первой.

## 8. Rewarded — Одноклассники

- [ ] При `vk_client=ok` определяется клиент OK.
- [ ] FAPI инициализируется.
- [ ] `FAPI.UI.loadAd()` подготавливает rewarded.
- [ ] Между подготовкой и показом соблюдается требуемый интервал.
- [ ] `FAPI.UI.showLoadedAd()` вызывается только после подготовки.
- [ ] Награда выдаётся только после успешного завершения.
- [ ] Отмена/ошибка не дают награду.
- [ ] После показа начинается подготовка следующей рекламы.

## 9. Lifecycle

- [ ] При скрытии/сворачивании игра ставится на паузу.
- [ ] Звук останавливается.
- [ ] При возврате игра восстанавливается.
- [ ] Нет двойного запуска музыки.
- [ ] Нет двойного начисления таймеров.
- [ ] Проверены `VKWebAppViewHide` / `VKWebAppViewRestore` там, где они доступны.
- [ ] Проверены `visibilitychange`, `blur`, `focus` как fallback.

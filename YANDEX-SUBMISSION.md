# Карточка и проверка Яндекс Игр — «Кот, который слишком хорошо живёт»

Актуализировано: 15.09.2026. Следующая сборка после проверки GitHub: **0.0.0.21**.

## Основные данные

- **Название RU:** Кот, который слишком хорошо живёт
- **Название EN:** The Cat Who Lives Too Well
- **Разработчик:** Mintyberries Games
- **Языки:** русский и английский
- **Категории:** казуальные, кликеры, симуляторы
- **Поддерживаемые платформы:** мобильные устройства и компьютеры
- **Ориентация:** **альбомная / landscape**
- **Игровая сцена:** единая виртуальная сцена 16:9; на телефоне в портретном положении показывается просьба повернуть устройство
- **Возрастной рейтинг:** 6+
- **Монетизация:** добровольная rewarded-реклама Яндекс Игр
- **Облачные сохранения:** Player API + локальная резервная копия

## Что обязательно проверить перед каждой отправкой

1. Открыть обычную RU-версию и пройти базовый цикл: кормление → покупка → блюдо → уровень → сохранение → перезагрузка.
2. Открыть EN-версию и проверить, что весь значимый текст на английском.
3. Проверить автоязык через `ysdk.environment.i18n.lang`:
   - `ru`, `be`, `kk`, `uk`, `uz` → русский;
   - остальные неподдерживаемые языки → английский.
4. Проверить landscape на Android и iOS: в portrait только заглушка поворота, элементы не деформируются.
5. Долгое нажатие/правый клик внутри игры не выделяет текст/картинки и не открывает контекстное меню.
6. Во время музыки и звуков **нет системного медиаплеера** ни в панели уведомлений Android, ни в браузере на ПК. Звук работает через Web Audio API.
7. При сворачивании окна/вкладки звук и геймплей останавливаются; после возврата корректно продолжаются.
8. После исчезновения заставки вызывается `LoadingAPI.ready()`; `GameplayAPI.start()/stop()` соответствуют реальному состоянию игры.
9. Rewarded-реклама запускается только после осознанного действия пользователя; до запуска ясно указана награда.
10. Во время рекламы звук и геймплей остановлены. При досрочном закрытии награда не выдаётся; после `onRewarded` выдаётся один раз.
11. Общий cooldown rewarded-рекламы в текущей игре — **5 минут (300 секунд)**.
12. Прогресс сохраняется сразу после значимых действий и восстанавливается после перезагрузки.
13. Нет браузерного скроллбара, swipe-to-refresh, наложений текста/кнопок, обрезанных активных элементов.
14. DevTools Console — без ошибок при старте, ресайзе, повороте, рекламе и возврате из background.
15. ZIP: `index.html` в корне; размер распакованного проекта <100 МБ; без пробелов/кириллицы в именах файлов и папок.
16. В релизный архив не попадают служебные материалы, исходные промо, временные папки и лишние файлы.

## Аудио

Музыка и игровые звуки воспроизводятся через **Web Audio API**, чтобы игра не регистрировалась как системный медиаплеер.

Перед сборкой 0.0.0.21 два звука «тыгыдык» из `assets/audio/zoomies-carpet-1.mp3` и `zoomies-carpet-2.mp3` планируется заменить на собственные записи. Пока замена не сделана, проверить условия лицензии исходных файлов и не забыть атрибуцию, если она требуется.

## Реклама

Используется только `ysdk.adv.showRewardedVideo`. В игре нет сторонних рекламных сетей и имитации рекламных блоков.

Основные награды:
- мгновенная выдача рыбов + доход ×3 на 5 минут;
- досрочное открытие отдельных секретных блюд.

Rewarded-реклама является бонусом: без неё основной игровой процесс остаётся доступным.

## Язык

Язык определяется через `ysdk.environment.i18n.lang`. Явные `?lang=ru` и `?lang=en` используются только для тестирования.

Fallback:
- `be`, `kk`, `uk`, `uz` → `ru`;
- остальные неподдерживаемые языки → `en`.

## Промоматериалы

В карточке Яндекс Игр используются **актуальные новые** скриншоты и геймплейное видео. Старые файлы в `submission-assets/` являются историческими и подлежат очистке отдельно.

Перед подачей проверить:
- минимум 2 актуальных скриншота для каждой заявленной платформы;
- реальный геймплей занимает ≥70% скриншота;
- нерекламное видео содержит реальный геймплей ≥70% длительности;
- RU-материалы показывают RU-интерфейс, EN-материалы — EN-интерфейс;
- нет интерфейса ОС, браузера или Яндекс Игр;
- иконка и обложка не являются скриншотами;
- название в игре, карточке и промоматериалах совпадает для каждого языка;
- нет рамок и скруглённых углов у загружаемых медиаматериалов.

## Комментарий разработчика для модерации

Игра работает только в альбомной ориентации и использует единую виртуальную сцену 16:9 на компьютерах и мобильных устройствах. В портретном положении на мобильных устройствах показывается просьба повернуть устройство.

Поддерживаются русский и английский языки. Язык автоматически определяется через `ysdk.environment.i18n.lang`; для `be/kk/uk/uz` используется русский резервный язык, для остальных неподдерживаемых языков — английский.

Прогресс сохраняется через Player API с резервной локальной копией. После готовности игры вызывается `LoadingAPI.ready()`. Gameplay API и звук приостанавливаются при сворачивании игры и показе рекламы.

Звук реализован через Web Audio API; системный медиаплеер браузера/ОС не используется. На игровом поле отключены выделение, drag, системное контекстное меню и iOS touch-callout.

В игре используется только добровольная rewarded-реклама через SDK Яндекс Игр. Перед просмотром игрок видит точное описание награды. Награда выдаётся только после события `onRewarded`.

## Служебные режимы

- `?test=1` — внутренний тестовый режим.
- `?layout=1` — внутренний визуальный редактор позиций.

Обычный пользовательский запуск и модерационный релиз не требуют этих параметров.

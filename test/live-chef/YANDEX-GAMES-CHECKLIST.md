# Чек-лист публикации игры в Яндекс Играх

**Версия чек-листа:** 15.09.2026  
**Назначение:** универсальная проверка перед первой публикацией и каждым обновлением игры.  
**Важно:** модерация указывает не полный список ошибок. Если найден один тип нарушения, нужно самостоятельно проверить **все места**, где он может повторяться.

> Источник истины перед каждой отправкой: актуальная страница «Требования к игре» в документации Яндекс Игр. Требования могут меняться — этот файл нужно периодически обновлять.

## 1. Архив и запуск — обязательный минимум

- [ ] SDK Яндекс Игр подключён и инициализируется по официальной схеме. **1.1, 1.19.1**
- [ ] Игра запускается без сторонней регистрации; если нужна авторизация — только Яндекс ID и только после осознанного действия пользователя. **1.2–1.2.2**
- [ ] В корне ZIP ровно один рабочий `index.html`. **1.22**
- [ ] В именах файлов/папок нет пробелов и кириллицы. **1.22**
- [ ] Размер всех файлов в распакованном виде ≤100 МБ. **1.21**
- [ ] Нет абсолютных ссылок на S3 Яндекса и технической привязки работоспособности к конкретному URL. **1.7, 1.18**
- [ ] Нет ошибок/вылетов/зависаний при старте, ресайзе, повороте, background/foreground, рекламе, долгом тапе, жестах и истории браузера. **1.14**
- [ ] Игра выглядит законченной: нет `TODO`, заглушек, debug-панелей, тестовых подписей и незавершённых экранов в обычном запуске. **1.15**
- [ ] Обновление не превращает существующую карточку в другую игру. **1.24**
- [ ] Интерактивный генеративный ИИ внутри игры не используется; заранее сгенерированные материалы допустимы. **1.23**

## 2. Мобильные устройства

- [ ] Игровая область занимает доступный экран; заявленная ориентация соответствует фактической. **1.6.1.1, 1.6.1.3**
- [ ] При неподдерживаемой ориентации показывается корректная заглушка/поворот, а не сломанная сцена. **1.6.1.3**
- [ ] Графика и UI не растягиваются непропорционально. **1.6.1.3**
- [ ] Все необходимые действия выполняются жестами/тачем. **1.6.1.5**
- [ ] **Нет системного медиаплеера** в шторке Android/iOS. Для игровой музыки и SFX предпочтительно Web Audio API. **1.6.1.6**
- [ ] Долгий тап нигде в игровом поле не выделяет текст/картинки и не вызывает системное контекстное меню/iOS callout. **1.6.1.8**
- [ ] Нет уведомлений/ошибок WebGL при запуске. **1.6.1.7**
- [ ] Интерактивные элементы достаточно крупные, между соседними кнопками нет опасных зон случайного нажатия. **1.8**
- [ ] Нет системного скролла и swipe-to-refresh во время игры. **1.10.2**

## 3. Десктоп

- [ ] Активное поле доходит по вертикали или горизонтали до края доступной области (кроме рекламной области). **1.6.2.1**
- [ ] Соотношение длинной и короткой стороны активного поля ≤2:1. **1.6.2.2**
- [ ] UI/графика не деформируются при ресайзе окна. **1.6.2.3**
- [ ] Игра полностью управляется мышью и/или клавиатурой. **1.6.2.4**
- [ ] **Нет системного медиаплеера** браузера/ОС. **1.6.2.5**
- [ ] Не используются системные горячие клавиши браузера/ОС как обязательное управление. **1.6.2.6**
- [ ] Правый клик/drag/выделение внутри игры не открывают системное меню и не выделяют игровое поле. **1.6.2.7**

## 4. Масштаб, интерфейс и управление

- [ ] При любых заявленных разрешениях активная сцена не выходит за экран, важные элементы не обрезаются. **1.10.1**
- [ ] Тексты не налезают на цифры/иконки/кнопки; длинные числа и локализованные строки проверены отдельно. **1.10.3**
- [ ] Основной игровой процесс доступен без постоянной внешней прокрутки страницы. **1.10.4**
- [ ] Размеры кнопок и объектов пригодны для выбранных платформ. **1.8**
- [ ] Если есть поля ввода на мобильном, клавиатура появляется при тапе по полю. **1.6.1.2**
- [ ] В DevTools Console нет ошибок. **рекомендация 6.4**
- [ ] Есть управление звуком; для игр с паузой желательно иметь явную паузу. **рекомендации 6.2–6.3**

## 5. Звук и пауза — зона повышенного риска

- [ ] При сворачивании вкладки/приложения **весь звук прекращается**. **1.3**
- [ ] При показе fullscreen/RV рекламы звук прекращается до закрытия рекламы. **4.7**
- [ ] При рекламе игровой процесс/таймеры также поставлены на паузу. **4.7**
- [ ] После возврата звук не запускается дважды и не создаёт несколько параллельных треков.
- [ ] На Android открыть шторку уведомлений во время музыки: карточки системного плеера игры быть не должно. **1.6.1.6**
- [ ] На ПК проверить Яндекс Браузер/Chrome: игра не появляется в системном/браузерном медиаконтроле. **1.6.2.5**
- [ ] На все звуки/музыку есть права; лицензии и обязательная атрибуция сохранены. **3.5**

## 6. Сохранения и состояние игры

- [ ] После каждого значимого действия прогресс сохраняется сразу либо есть явная кнопка сохранения. **1.9**
- [ ] Обновление страницы не теряет уровни, валюту, достижения и купленные элементы. **1.9, 2.6**
- [ ] Поворот устройства/resize не сбрасывает прогресс. **1.9**
- [ ] Если заявлены облачные сохранения, это отмечено в черновике. **1.11**
- [ ] Если есть инап-покупки, прогресс хранится на сервере и доступен на разных устройствах. **1.13.3**
- [ ] После перехода по рекламе и возврата состояние игры сохраняется. **4.2**

## 7. SDK: Game Ready и Gameplay API

- [ ] `LoadingAPI.ready()` вызывается **только когда ресурсы загружены и пользователь реально может начать играть**. **1.19.2**
- [ ] `GameplayAPI.start()` соответствует реальному началу/возобновлению геймплея. **1.19.3**
- [ ] `GameplayAPI.stop()` вызывается при рекламе, паузе, уходе во вкладку/background и других остановках геймплея. **1.19.3**
- [ ] Если используются `game_api_pause` / `game_api_resume`, игра действительно останавливается/возобновляется вместе со звуком и таймерами. **1.19.4**
- [ ] В debug-панели Яндекс Игр Game Ready показывает корректное состояние; проверить новый loader (`IT`), если он используется.

## 8. Реклама

- [ ] Монетизация РСЯ подключена. **1.12**
- [ ] Вся реклама вызывается только SDK Яндекс Игр; сторонних сетей/статичных «рекламных» изображений нет. **4.1**
- [ ] Встроенные рекламные блоки Яндекса не модифицируются и не имитируются собственным HTML. **1.16**
- [ ] Ориентация рекламных блоков соответствует игре. **4.3**
- [ ] Реклама показывается предсказуемо и в логической паузе. **4.4**
- [ ] Rewarded Video запускается только добровольно — после кнопки/действия пользователя. **4.5**
- [ ] До запуска RV ясно написано **«посмотреть рекламу»** и точная награда. **4.5.1**
- [ ] Награда RV — дополнительный бонус, без неё можно продолжать основной игровой процесс. **4.5.2**
- [ ] Награда выдаётся только после подтверждения просмотра (`onRewarded`), не по `onOpen`/`onClose`.
- [ ] Досрочное закрытие RV → награды нет.
- [ ] Повторные клики во время загрузки рекламы не создают второй показ/двойную награду.
- [ ] Во время полноэкранной рекламы игра и звук стоят на паузе. **4.7**
- [ ] Если используются дополнительные баннеры — это разрешённые sticky-баннеры, не кастомный RTB. **4.6**

## 9. Язык и локализация

- [ ] В черновике выбран только тот язык, который реально полностью поддерживается игрой. **2.10**
- [ ] Язык автоматически определяется через `ysdk.environment.i18n.lang`. **2.14**
- [ ] Резервная схема: `be/kk/uk/uz → ru`, остальные неподдерживаемые языки → `en`.
- [ ] Все значимые тексты, кнопки, подсказки, окна рекламы/ошибок и динамические сообщения переведены. **8.2.3**
- [ ] В RU-запуске нет английских игровых строк; в EN-запуске нет русских игровых строк (кроме допустимых собственных имён/бренда). **8.2.3**
- [ ] Проверены длинные EN-строки: ничего не обрезается и не накладывается. **1.10.3**
- [ ] Название игры на каждом языке совпадает в игре, карточке и промоматериалах. **5.1.3**
- [ ] Если есть ручной переключатель языка, он понятен без знания текущего языка. **рекомендация 6.9**

## 10. Игровое содержание и качество

- [ ] Игра соответствует заявленному жанру и содержит настоящие игровые механики. **2.3–2.4**
- [ ] Есть понятный сеттинг/цель и развитие сложности/прогрессии. **2.8**
- [ ] Основного содержания хватает более чем на 10 минут. **2.9**
- [ ] В игре/карточке описано управление. **2.2**
- [ ] Возрастной рейтинг соответствует содержанию. **2.7**
- [ ] Нет эзотерики/гаданий, запрещённых политических/религиозных материалов, реалистичной жестокости к детям/животным и предсказаний о здоровье/смерти. **3.4**
- [ ] Нет реальных денежных выигрышей, физических призов, азартной игры/лотереи/интернет-магазина. **3.7**
- [ ] Игра не является клоном другой игры каталога или дубликатом собственной игры без существенной переработки. **3.6**
- [ ] Если в игре есть видео, оно не встроено через YouTube-плеер с возможностью уйти наружу. **3.9**

## 11. Авторские права и лицензии

- [ ] Есть права на каждое изображение, шрифт, звук, музыку, видео и логотип. **3.5**
- [ ] Для каждого стороннего ассета сохранены источник, автор, тип лицензии и дата скачивания.
- [ ] Если лицензия требует attribution, кредит присутствует **в самой игре**, а не только в репозитории.
- [ ] Облачные/Google-шрифты не используются без необходимости; если шрифт локальный — есть право на распространение.
- [ ] Никаких чужих брендов/логотипов без прав; особенно проверить заставку, «Как играть», сертификаты, декор и промоматериалы.

## 12. Карточка и медиаматериалы

- [ ] Заполнены все обязательные поля: название, «Об игре», «Как играть», версия, категории, иконка, обложка, архив, платформы, ориентация, скриншоты. **5.2**
- [ ] Форматы/размеры/длительности соответствуют текущим ограничениям формы Консоли. **5.3**
- [ ] Теги соответствуют игре. **5.4**
- [ ] Иконка и обложка — отдельные промоматериалы, **не скриншоты**. **5.6**
- [ ] Скриншоты показывают актуальный реальный геймплей ≥70% кадра. **5.1.1.2**
- [ ] Нерекламное видео показывает реальный геймплей ≥70% длительности. **5.1.1.3**
- [ ] Материалы соответствуют именно этой игре; не повторяются между разными играми. **5.1.1–5.1.1.1**
- [ ] На медиа нет рамок/скруглённых углов. **8.3.3**
- [ ] На медиа нет статус-бара телефона, батареи, вкладок/панелей браузера и интерфейса Яндекс Игр. **8.3.4**
- [ ] Нет пиксельных артефактов, сильного затемнения, обрезанного текста. **8.3.1**
- [ ] RU-скриншоты сняты из RU-версии, EN — из EN-версии. **8.2.3**
- [ ] Название/описание/«Как играть» честно отражают реальную механику. **8.2.2**
- [ ] Нет внешних ссылок, URL и призывов перейти на сторонний сайт/стор/полную версию. **8.4.2–8.4.4**

## 13. Финальная матрица тестирования перед кнопкой «На модерацию»

- [ ] Windows + Яндекс Браузер: запуск, звук, ресайз, rewarded, background/foreground, правый клик.
- [ ] Windows + Chrome/Firefox: базовый цикл и звук.
- [ ] Android + Яндекс Браузер: landscape, longtap, шторка уведомлений, звук, реклама, возврат из background.
- [ ] Android + Chrome: базовый цикл.
- [ ] iPhone/iPad + Safari: landscape, longtap, выделение/контекстное меню, звук, реклама, перезагрузка.
- [ ] RU: обычный запуск без тестовых параметров.
- [ ] EN: обычный запуск и все динамические окна.
- [ ] Язык из группы `be/kk/uk/uz`: получаем RU.
- [ ] Любой другой неподдерживаемый язык (например `de`/`pl`): получаем EN.
- [ ] Чистый профиль/инкогнито: первый запуск не зависит от старого localStorage/cache.
- [ ] Медленная сеть/ошибка рекламы: игра не зависает и не выдаёт награду ошибочно.
- [ ] Перезагрузка после покупки/уровня: прогресс восстановился.
- [ ] Финальный ZIP распакован и запущен локально/в черновике именно в том виде, который отправляется.

## 14. Ошибки, которые уже реально находила модерация — проверять в каждом будущем проекте

- [ ] **Системный плеер на Android** — обычный HTML Audio может появляться в панели уведомлений. Проверять и при необходимости использовать Web Audio API. **1.6.1.6**
- [ ] **Системный плеер на desktop** — игра не должна регистрироваться в медиаконтроле браузера/ОС. **1.6.2.5**
- [ ] **Longtap / context menu на iOS** — глобально отключить выделение, `-webkit-touch-callout`, `dragstart`, `selectstart`, `contextmenu` внутри игрового поля. **1.6.1.8 / 1.6.2.7**
- [ ] **Язык** — не просто `ru/en`, а корректный SDK-fallback: `be/kk/uk/uz → ru`, остальные → `en`. **2.14**
- [ ] **Скриншоты** — должны быть из текущей версии, на нужном языке и соответствовать фактическому интерфейсу. **5.1.1.2 / 8.2.3 / 8.3.1**
- [ ] **Чужой бренд** — не оставлять название/логотип платформы или стороннего сервиса в «Как играть», интерфейсе или медиа без необходимости/прав. **3.5 / 8.4**
- [ ] **Перекрытия UI** — отдельно тестировать большие значения счётчиков и длинные локализованные строки. **1.10.3**
- [ ] **Звук по лицензии** — бесплатный ассет может требовать атрибуцию; «free» не означает «без условий». **3.5**

## 15. Перед каждым новым проектом

- [ ] В первый день разработки заложить SDK, адаптив, паузу, Web Audio, сохранения и локализацию — не оставлять это на модерацию.
- [ ] Сразу вести `AUDIO-LICENSES.md` / `ASSET-LICENSES.md`.
- [ ] Сразу иметь RU + EN словарь, а не переводить строки вручную по файлам в конце.
- [ ] Делать отдельный `release checklist` и не собирать архив из рабочей папки целиком.
- [ ] Хранить предыдущую рабочую версию отдельной веткой/тегом перед каждой серьёзной модерационной правкой.
- [ ] После каждого отказа добавлять найденный кейс в этот чек-лист — модерация приводит примеры, а не полный перечень проблем.
